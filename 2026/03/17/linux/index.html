#解压

怎么查看基本的日志文件

sudo cat /var/log/syslog # Ubuntu/Debian 系统日志
sudo cat /var/log/messages # CentOS/RHEL 系统日志
sudo cat /var/log/auth.log # 认证日志（Ubuntu/Debian）
sudo cat /var/log/secure # 认证日志（CentOS/RHEL）
sudo cat /var/log/kern.log # 内核消息
sudo cat /var/log/boot.log # 系统启动日志

常用的二进制文件目录怎么给文件赋权

chmod 755 script.sh #所有者可读写执行，其他人可读执行（
chmod 644 script.sh #普通文件权限

怎么运行可执行文件怎么递归删除

可执行文件

递归删除

rm -rf directory/
rm -r directory/

学会使用 find，grep 查找 flag 在哪些文件中

grep "flag" * #在当前目录所有文件里面找flag
grep -r "flag" /home/user/documents/ #在指定目录搜索
grep -rE "(flag|FLAG|ctf)\{[^}]+\}" #识别多种格式
find . -name "flag.txt" # 精确匹配文件名
find . -name "*.txt" #所有txt结尾文件
find . -name "flag*" #以flag开头的文件
