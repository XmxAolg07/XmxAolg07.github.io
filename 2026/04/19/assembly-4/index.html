GDB调试学习笔记

什么是GDB

GDB（GNU Debugger）是Linux下的C/C++调试工具，可以让你一步步运行程序，查看变量值，查看汇编指令，找出bug。

准备工作：编译时加调试信息

# 必须加 -g 选项，否则无法调试
gcc -g -o program program.c

# 查看汇编代码需要加 -S 或使用objdump
gcc -S -o program.s program.c  # 生成汇编文件

# 编译时保留汇编符号
gcc -g -o program program.c

启动GDB

# 方式1：直接调试程序
gdb ./program

# 方式2：先启动gdb，再加载程序
gdb
file ./program

# 方式3：调试带参数的程序
gdb --args ./program arg1 arg2

核心命令速查表

命令 简写 作用
break b 设置断点
run r 运行程序
continue c 继续运行到下一个断点
next n 单步执行（不进入函数）
step s 单步执行（进入函数）
print p 打印变量值
list l 查看源代码
backtrace bt 查看函数调用栈
info i 查看信息
quit q 退出GDB

汇编调试相关命令

命令 简写 作用
disassemble disas 查看汇编代码
stepi si 单步执行一条汇编指令
nexti ni 单步执行（不进入函数调用）
info registers i r 查看寄存器值
print $rax p $rax 打印寄存器值
x x 查看内存
layout asm - 显示汇编布局
layout reg - 显示寄存器布局

常用操作示例

1. 设置断点

# 在函数处打断点
(gdb) break main
(gdb) b main

# 在行号处打断点
(gdb) b 15

# 在文件指定行打断点
(gdb) b test.c:20

# 条件断点（i==5时才停下）
(gdb) b 15 if i == 5

# 查看所有断点
(gdb) info breakpoints
(gdb) i b

# 删除断点（编号1）
(gdb) delete 1
(gdb) d 1

# 禁用断点
(gdb) disable 1

# 启用断点
(gdb) enable 1

2. 运行和控制

# 开始运行
(gdb) run
(gdb) r

# 继续执行
(gdb) continue
(gdb) c

# 单步执行（不进入函数）
(gdb) next
(gdb) n

# 单步执行（进入函数）
(gdb) step
(gdb) s

# 汇编级单步
(gdb) stepi   # 执行一条汇编指令
(gdb) si
(gdb) nexti   # 执行一条汇编指令（不进入调用）
(gdb) ni

# 执行到当前函数返回
(gdb) finish

3. 查看变量和内存

# 打印变量值
(gdb) print i
(gdb) p i

# 打印表达式
(gdb) p i * 2 + 3

# 查看数组内容
(gdb) p arr[0]@10    # 打印arr前10个元素

# 查看指针指向的内容
(gdb) p *ptr

# 查看变量类型
(gdb) ptype i

# 查看内存
(gdb) x/10x addr      # 16进制显示10个单元
(gdb) x/10d addr      # 10进制显示
(gdb) x/s addr        # 显示字符串
(gdb) x/10i addr      # 显示10条汇编指令

# 显示格式：x/数量格式大小
# 格式：x(hex) d(dec) s(string) c(char) i(instruction)
# 大小：b(byte) h(halfword) w(word) g(giant)

4. 查看汇编和寄存器

# 查看当前函数汇编代码
(gdb) disassemble
(gdb) disas

# 查看指定函数汇编
(gdb) disas main

# 查看指定地址范围汇编
(gdb) disas 0x401000,0x401010

# 查看所有寄存器
(gdb) info registers
(gdb) i r

# 查看特定寄存器
(gdb) p $rax
(gdb) p $rbx
(gdb) p $rip   # 指令指针
(gdb) p $rsp   # 栈指针

# 查看寄存器值（16进制）
(gdb) p/x $rax

# 查看内存中的汇编指令
(gdb) x/10i $rip

5. 源码和汇编混合显示

# 进入TUI模式
(gdb) layout asm    # 显示汇编代码
(gdb) layout reg    # 显示寄存器
(gdb) layout split  # 源码和汇编分屏显示

# TUI快捷键
# Ctrl+X A：退出TUI模式
# Ctrl+X 1：单窗口
# Ctrl+X 2：双窗口
# Ctrl+X O：切换窗口焦点
# Ctrl+L：刷新屏幕

示例程序（add.c）

#include <stdio.h>

int add(int a, int b) {
    return a + b;
}

int main() {
    int x = 10;
    int y = 20;
    int z = add(x, y);
    printf("Result: %d\n", z);
    return 0;
}

编译并调试

# 编译（保留调试信息和符号）
gcc -g -o add add.c

# 启动gdb
gdb ./add

汇编调试实用技巧

查看指令执行过程

# 显示当前将要执行的指令
(gdb) x/i $rip
=> 0x555555555149 <main+8>: movl   $0xa,-0xc(%rbp)

# 显示下5条指令
(gdb) x/5i $rip

# 显示当前函数的完整汇编
(gdb) disas

# 显示并标注源码对应关系
(gdb) disas /m

条件断点在汇编级别

# 当rax等于特定值时停下
(gdb) b *0x555555555145 if $rax == 30

# 当内存地址的值变化时停下
(gdb) watch *(int*)0x7fffffffe3bc

查看栈帧信息

# 查看当前栈帧
(gdb) info frame

# 查看所有栈帧
(gdb) bt

# 查看栈内存
(gdb) x/20x $rsp

x86-64 常用寄存器

寄存器 作用
rax 返回值、累加器
rbx 通用寄存器
rcx 第4个参数、计数器
rdx 第3个参数、数据寄存器
rsi 第2个参数
rdi 第1个参数
rbp 栈基址指针
rsp 栈指针
rip 指令指针
r8-r15 通用寄存器
