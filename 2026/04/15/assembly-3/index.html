汇编进阶3

一、条件判断指令

1. CMP 指令（Compare）

指令 作用 对标志位的影响
cmp dest, src 计算 dest - src， 不保存结果 ，仅影响标志位 ZF, CF, OF, SF, AF, PF

assembly

cmp ax, 10      ; AX - 10，结果丢弃，只影响标志位

2. 条件跳转指令（Conditional Jump）

指令 全称 跳转条件 适用场景
JE Jump if Equal ZF = 1 相等则跳
JZ Jump if Zero ZF = 1 结果为零则跳
JNE Jump if Not Equal ZF = 0 不相等则跳
JNZ Jump if Not Zero ZF = 0 结果非零则跳

无符号数比较：

指令 全称 跳转条件 含义
JA Jump if Above CF=0 且 ZF=0 大于则跳（无符号）
JNBE Jump if Not Below or Equal 同上 同上
JB Jump if Below CF=1 小于则跳（无符号）
JNAE Jump if Not Above or Equal 同上 同上
JAE Jump if Above or Equal CF=0 大于等于则跳
JBE Jump if Below or Equal CF=1 或 ZF=1 小于等于则跳

有符号数比较：

指令 全称 跳转条件
JG Jump if Greater SF=OF 且 ZF=0
JL Jump if Less SF≠OF
JGE Jump if Greater or Equal SF=OF
JLE Jump if Less or Equal SF≠OF 或 ZF=1

3. 条件判断代码实例

assembly

section .text
    global _start

_start:
    mov ax, 10
    cmp ax, 10

    je  equal_label      ; 相等则跳转
    jmp not_equal_label  ; 不相等则继续

equal_label:
    mov rbx, 1           ; 相等时执行
    jmp exit

not_equal_label:
    mov rbx, 0           ; 不相等时执行

exit:
    mov rax, 60
    xor rdi, rdi
    syscall

4. ADC 指令（Add with Carry）

指令 作用 公式
adc dest, src 带进位加法 dest = dest + src + CF

应用场景：大数加法（超过寄存器位宽）

assembly

; 计算 0x12345678 + 0x9ABCDEF0（64位无法一次完成时）
mov ax, 0x5678
mov bx, 0xDEF0
add ax, bx          ; 低位相加，可能产生进位
mov cx, 0x1234
mov dx, 0x9ABC
adc cx, dx          ; 高位相加，加上低位的进位
; 结果：CX:AX

5. SBB 指令（Subtract with Borrow）

指令 作用 公式
sbb dest, src 带借位减法 dest = dest - src - CF

assembly

; 大数减法
mov ax, 0x5678
mov bx, 0x1234
sub ax, bx          ; 低位相减
mov cx, 0x1234
mov dx, 0x1000
sbb cx, dx          ; 高位相减，减去借位
; 结果：CX:AX

二、循环指令 LOOP

1. LOOP 指令详解

指令 操作流程 CX/ECX/RCX 变化
loop label 1. CX = CX - 1``2. 若 CX ≠ 0，跳转到 label 自动递减

注意 ：loop 默认使用 CX （16位）、 ECX （32位）或 RCX （64位）作为计数器。

2. 循环相关指令

指令 全称 跳转条件
loop label Loop CX ≠ 0 时跳转
loope label Loop while Equal CX ≠ 0且 ZF=1 时跳转
loopz label Loop while Zero 同上
loopne label Loop while Not Equal CX ≠ 0且 ZF=0 时跳转
loopnz label Loop while Not Zero 同上

3. 等差数列求和实例

assembly

; 计算 1 + 2 + 3 + ... + 100 的和
section .text
    global _start

_start:
    mov rcx, 100        ; 循环次数（计数器）
    xor rax, rax        ; 累加和清零
    mov rbx, 1          ; 当前项数值

sum_loop:
    add rax, rbx        ; 累加：sum = sum + i
    inc rbx             ; 下一项：i = i + 1
    loop sum_loop       ; RCX--，若不为0则跳转

    ; 此时 RAX = 5050（1+2+...+100）

exit:
    mov rax, 60
    xor rdi, rdi
    syscall

三、函数调用指令 CALL 与 RET

1. CALL 指令

指令格式 操作 本质
call near label 1. 将下一条指令地址（IP）压栈``2. IP = label 的偏移地址 段内调用
call far ptr label 1. 将 CS 压栈 2. 将 IP 压栈3. CS:IP = 新的段:偏移 段间调用
call reg 将 IP 压栈，IP = 寄存器值 间接调用
call [mem] 将 IP 压栈，IP = 内存值 内存间接调用

2. RET 指令

指令格式 操作 本质
ret 1. 从栈顶弹出 IP``2. 跳转到该地址执行 段内返回
ret far 1. 从栈顶弹出 IP 2. 从栈顶弹出 CS3. 跳转到 CS:IP 段间返回
ret n 1. 弹出 IP``2. SP = SP + n（清理参数） 带参数清理的返回

3. 栈在 CALL/RET 中的作用

text

调用前：
SP → [ 栈顶空闲 ]
----------------
执行 call near proc 后：
SP → [ 返回地址 (IP) ]  ← 自动压入
     [ 之前的数据... ]
----------------
执行 ret 后：
SP → [ 之前的数据... ]  ← 返回地址被弹出

4. 函数调用完整实例

assembly

section .text
    global _start

_start:
    mov rax, 5
    mov rbx, 3

    call add_numbers    ; 调用函数

    ; 结果在 RAX 中（应为 8）

    mov rax, 60
    xor rdi, rdi
    syscall

; ------------------------------------------------------------
; 函数：add_numbers
; 输入：RAX, RBX
; 输出：RAX = RAX + RBX
; ------------------------------------------------------------
add_numbers:
    add rax, rbx
    ret                 ; 返回调用处

5. CALL FAR PTR 示例（实模式）

assembly

; 实模式下的远调用
call far ptr 0x1000:0x0000   ; 调用另一段的代码

; 等效操作（手动模拟）
push cs          ; 先压入当前代码段
push offset next ; 再压入返回地址
jmp 0x1000:0x0000
next:
    ; 返回后继续执行

四、段定义与 DUP 指令

1. 三个核心段

段名称 英文 寄存器 用途
代码段 Code Segment CS 存放可执行指令
数据段 Data Segment DS 存放已初始化的数据
栈段 Stack Segment SS 存放栈空间

2. 段定义语法

assembly

section .text                    ; 代码段
    global _start
_start:
    ; 指令代码

section .data                    ; 数据段（已初始化）
    msg db 'Hello', 0xA
    array dw 1, 2, 3, 4, 5
    value dq 0x12345678

section .bss                     ; 数据段（未初始化）
    buffer resb 64               ; 保留 64 字节
    big_array resd 100           ; 保留 100 个双字

3. DUP 指令（重复定义）

DUP 用于批量定义相同数据，MASM/TASM 语法中常用。

格式 含义 示例
count DUP(value) 重复 count 次 value db 10 DUP(0)
count DUP(?) 重复 count 次，不初始化 dw 20 DUP(?)
嵌套 DUP 多维重复 db 3 DUP(1, 2 DUP(0))

MASM/TASM 语法示例：

assembly

; 定义 100 个字节，全部为 0
buffer db 100 DUP(0)

; 定义 50 个字，未初始化
array dw 50 DUP(?)

; 定义字符串模板（10 个星号）
stars db 10 DUP('*')

; 嵌套：定义 3 组，每组是 1, 0, 0
; 结果：1,0,0, 1,0,0, 1,0,0
pattern db 3 DUP(1, 2 DUP(0))

NASM 等效写法：

NASM 不使用 DUP，使用 times 指令：

assembly

buffer times 100 db 0
array  times 50  dw 0
stars  times 10  db '*'

五、综合示例：完整程序框架

assembly

; ============================================================
; 综合示例：展示段定义、循环、条件判断、函数调用
; ============================================================

section .data
    msg     db 'Sum: ', 0
    newline db 0xA, 0
    arr     times 10 dw 1    ; 10 个元素，每个初始化为 1

section .bss
    sum     resq 1           ; 保留 8 字节存结果

section .text
    global _start

_start:
    ; 计算数组元素和
    mov rcx, 10              ; 循环 10 次
    xor rax, rax             ; 累加和清零
    mov rbx, arr             ; 数组首地址

sum_loop:
    add ax, word [rbx]       ; 累加
    add rbx, 2               ; 指向下一个元素（word=2字节）
    loop sum_loop

    mov [sum], rax           ; 保存结果

    ; 判断结果是否大于 10
    cmp rax, 10
    ja  above_10
    jmp exit

above_10:
    ; 结果大于 10 的处理
    call do_something

exit:
    mov rax, 60
    xor rdi, rdi
    syscall

do_something:
    ; 函数体
    ret
