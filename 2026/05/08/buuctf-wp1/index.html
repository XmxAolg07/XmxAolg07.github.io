通过这里，我们可以看出此题的加密逻辑

把第[2]个字符变为[2]和[3]的ASCII码减少50

把第[4]个字符变为[2]和[5]的ASCII码减少48

把第[30]个字符变为[31]和[9]的ASCII码减少48

把第[14]个字符变为[27]和[27]的ASCII码减少97

把整个数组逆序处理

运算 ((input1[i] + i) % 128 + 128) % 128 其实就是(input1[i] + i) % 128

再看第二部分

for i in range(l - 1):
    code[i] = code[i] ^ code[i + 1]

这是从前往后，将每个元素与后一个元素异或

再根据给出的数据我们写出解密脚本

code = [
    '\x1f', '\x12', '\x1d', '(', '0', '4', '\x01', '\x06',
    '\x14', '4', ',', '\x1b', 'U', '?', 'o', '6',
    '*', ':', '\x01', 'D', ';', '%', '\x13'
]
final_code = [ord(c) if isinstance(c, str) else c for c in code]
l = len(final_code)
xorred_code = [0] * l
xorred_code[l-1] = final_code[l-1]
for i in range(l-2, -1, -1):
    xorred_code[i] = final_code[i] ^ xorred_code[i+1]
input1 = []
for i in range(l):
    ch = (xorred_code[i] - i) % 128
    input1.append(chr(ch))
flag = ''.join(input1)
print(flag)
